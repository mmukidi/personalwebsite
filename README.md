# personalwebsite

Manohar's personal daily brief. `index.html` is a single self-contained page (open it in any browser) with four tabs:

- **Today & Gmail**: summary of the last two days of inbox mail (snapshot, Oct 17, 2026).
- **Lottery**: next Powerball and Mega Millions picks, hot and overdue numbers and recent draws, built from the goldie-lottery repo (`lottery.json`).
- **Stocks**: summary of the "Stocks-exponential moving average" project (EMA crossover idea plus the stocksmodel ORB trading plan, risk rules and agent team).
- **Agents**: overview of the agents and projects behind the site.

## Docs (all files sit at the repo root)
- `agents.md`: what each agent does and where it lives.
- `goldie-lottery-README.md`: copy of the goldie-lottery README.
