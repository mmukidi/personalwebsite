# personalwebsite

Manohar's personal daily brief. `index.html` is a single self-contained page (open it in any browser) with four tabs:

- **Today & Gmail**: summary of the last two days of inbox mail (snapshot, Oct 17, 2026).
- **Lottery**: next Powerball and Mega Millions picks, hot and overdue numbers and recent draws, built from the goldie-lottery repo (`data/lottery.json`).
- **Stocks**: slot for the "Stocks-exponential moving average" project (not connected yet).
- **Agents**: overview of the agents and projects behind the site.

## Docs
- `docs/agents.md`: what each agent does and where it lives.
- `docs/goldie-lottery-README.md`: copy of the goldie-lottery README.
